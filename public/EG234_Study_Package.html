Metal Forming
// Concepts · Formulas · Worked Examples
Core Definitions B1
Cold Working
Metal deformation below recrystallization temperature. Causes strain hardening, better surface finish, tighter tolerances. Requires more force.
Hot Working
Deformation above recrystallization temperature. No strain hardening, easier to deform, suitable for large deformations. Rougher finish.
Forging
Compressive force applied to shape metal between dies. Can be open-die (flat dies) or closed-die (shaped dies).
Rolling
Metal passed between rollers to reduce thickness or change cross-section. Volume is conserved throughout the process.

Key Formulas MEMORISE

1. Volume Conservation (Forging / Rolling)

V₁ = V₂ A₁ × L₁ = A₂ × L₂

2. Blank Diameter — Deep Drawing

D = √(d² + 4dh) where: D = blank diameter, d = cup diameter, h = cup height

3. Forging Load

F = σ_f × A where: σ_f = average flow stress (MPa), A = cross-sectional area (mm²)

4. Area of Circle

A = π/4 × D² = πr²
Worked Example — Volume Conservation B2

A square billet 50×50 mm is forged into a circular rod of 40 mm diameter. Find the length of the rod (assuming original billet length = L₁).

// Step-by-Step Solution
Step 1: Volume of square billet = 50 × 50 × L₁ = 2500·L₁ mm³
Step 2: Area of circular rod = π/4 × 40² = 1256.6 mm²
Step 3: Volume conserved → 2500·L₁ = 1256.6 × L₂
Step 4: L₂ = (2500 / 1256.6) × L₁ = 1.99 × L₁
∴ Rod length ≈ 2 × original billet length
Worked Example — Deep Drawing B3

Cup diameter = 120 mm, height = 50 mm, thickness = 2 mm. Find blank diameter.

// Step-by-Step Solution
Formula: D = √(d² + 4dh)
D = √(120² + 4 × 120 × 50)
D = √(14400 + 24000)
D = √38400
∴ Blank Diameter D = 195.96 ≈ 196 mm
Worked Example — Forging Load B4

Cylinder: diameter = 100 mm, height = 50 mm, flow stress = 200 MPa.

// Step-by-Step Solution
Step 1: Cross-sectional area A = π/4 × 100² = 7854 mm²
Step 2: Forging Load F = σ_f × A
F = 200 MPa × 7854 mm²
∴ F = 1,570,800 N = 1.57 MN

Sand Casting
// Concepts · Process Steps · Worked Problems
What is Sand Casting? INTRO

Sand casting is a metal casting process where molten metal is poured into a sand mold cavity. It accounts for approximately 70% of all metal castings worldwide. One of the oldest and most versatile casting methods.

Key Components KNOW THIS
Pattern
Replica of final part with allowances. Materials: wood, plastic, metal. Types: solid, split, match-plate, cope-and-drag.
Molding Sand
Base sand (silica) + Binder (clay/bentonite) + Additives. Must have permeability, strength, collapsibility.
Core
Creates internal cavities/hollow sections. Made from sand with special binders. Placed in mold cavity before pouring.
Gating System
Sprue (vertical channel) → Runner (horizontal) → Gates (entry to cavity). Riser compensates for shrinkage.
Pattern Allowances FORMULAS
1. Shrinkage Allowance: Pattern size = Final size ÷ (1 - shrinkage fraction) e.g. steel: 2% → divide by 0.98 2. Machining Allowance: Add per side (1.5–6 mm) to all surfaces to be machined 3. Draft Allowance: Taper dimension = Height × tan(draft angle) Typical: 1–3°
// Worked Example — Pattern Dimensions (Problem 1)
Final casting length = 200 mm, shrinkage = 2%, machining = 3mm/side, draft = 2°
Shrinkage: 200 ÷ (1 - 0.02) = 200 ÷ 0.98 = 204.08 mm
Machining: 204.08 + (3 × 2) = 204.08 + 6 = 210.08 mm
Draft: 210 × tan(2°) = 210 × 0.0349 = 7.33 mm taper
∴ Pattern length = 210.08 mm with 7.33 mm taper over height
Chvorinov's Rule — Solidification Time KEY FORMULA
t = k × (V/A)² where: t = solidification time (min) k = mold constant (min/cm²) V = volume (cm³) A = surface area (cm²) V/A = modulus of casting RISER RULE: (V/A)_riser > (V/A)_casting → Riser must solidify AFTER the casting
// Worked Example — Solidification (Problem 5)
Plate: 20×30×2 cm, k = 2.0 min/cm²
V = 20×30×2 = 1200 cm³
A = 2(20×30) + 2(20×2) + 2(30×2) = 1200 + 80 + 120 = 1400 cm²
V/A = 1200/1400 = 0.857 cm
t = 2.0 × (0.857)² = 2.0 × 0.734
∴ Solidification time = 1.47 minutes
Riser Design WORKED

For cylindrical riser with H = D:

V/A = D/6 (when H = D) So: D/6 = required V/A ratio → solve for D For H = 1.5D: V/A = 0.1875D So: 0.1875D > (V/A)_casting → solve for D
// Worked Example — Riser for Plate Casting
Casting V/A = 0.857 cm (from above), H = 1.5D
Riser V/A = 0.1875D > 0.857
D > 0.857 / 0.1875 = 4.57 cm → choose D = 5 cm
H = 1.5 × 5 = 7.5 cm
Check: V/A = 0.1875 × 5 = 0.9375 > 0.857 ✓
∴ Riser: D = 5 cm, H = 7.5 cm
Gating System Design PROBLEM 3
Flow rate: Q = Volume / time Choke area: A = Q / [Cd × √(2gh)] where Cd = discharge coefficient (~0.9) h = effective sprue height
// Worked Example — Gating (Problem 3)
Aluminum casting: 10 kg, pour in 10 s, sprue height = 150 mm, basin = 50 mm
Volume = 10/2700 = 0.003704 m³
Q = 0.003704 / 10 = 0.0003704 m³/s
h = 0.05 + 0.15 = 0.20 m
A = 0.0003704 / [0.9 × √(2×9.81×0.20)] = 0.0003704 / 1.783
∴ Choke area = 207.5 mm² → sprue base diameter = 16.25 mm

Process Planning & Costing
// Operations · Sequencing · Cost Calculations
Process Planning Principles KEY
Base First
Machine the primary datum/reference surface first to ensure everything else is referenced from it.
Roughing Before Finishing
Remove bulk material first, then do precision operations to avoid wasting time on fine cuts in thick stock.
Accuracy Principle
Perform critical/precision operations last to minimise error accumulation.
Similarity Principle
Group similar operations together to reduce setup changes and machine idle time.
Manufacturing Cost Components MEMORISE
Total Manufacturing Cost = DM + DL + Machine Cost + Overhead DM = Direct Material = (Volume × Density × material rate) - scrap recovery DL = Direct Labor = Total labor hours × wage rate MC = Machine Cost = Machine hours × machine rate OH = Overhead = % of DL (e.g. 150% × DL) Total hours = Setup time + (Cycle time × Quantity)
Worked Example — Batch Costing (100 Bushings) FROM NOTES

Material: mild steel @ $8/kg | Labor: $24/hr | Machine: $40/hr | Overhead: 150% DL | Setup: 40 min | Cycle: 10 min/piece

// Material Cost per Piece
Volume = π × 35² × 61 = 234,885 mm³ = 234.9 cm³
Weight = 234.9 × 7.85 g/cm³ = 1,844 g = 1.844 kg
Material cost = 1.844 × $8 = $14.75
Scrap recovery (30% @ $2/kg) = $0.88
Net material cost = $14.75 - $0.88 = $13.87/piece
// Labor & Overhead (100 pieces)
Setup = 40 min = 0.667 hr | Processing = 100 × 10 = 1000 min = 16.667 hr
Total hours = 17.334 hr
DL = 17.334 × $24 = $416.02 → per piece = $4.16
Machine = 17.334 × $40 = $693.36 → per piece = $6.93
Overhead = 150% × $416.02 = $624.03 → per piece = $6.24
Total cost per piece = $13.87 + $4.16 + $6.93 + $6.24 = $31.20
Worked Example — Precision Shafts (Tutorial) BATCH vs JOB

Batch of 250 shafts | Material: $18.50/shaft | Setup: 90 min | Cycle: 8 min | Labor: $30/hr | Machine: $60/hr | Overhead: 200% DL

// Batch Production (250 units)
DM = 250 × $18.50 = $4,625.00
Total hours = 1.5 hr setup + (250 × 8/60) = 1.5 + 33.33 = 34.83 hr
DL = 34.83 × $30 = $1,045.00
Machine = 34.83 × $60 = $2,090.00
Overhead = 200% × $1,045 = $2,090.00
Total batch = $9,850 → Cost per shaft = $39.40
// Job Production (10 units, 3hr setup)
DM = 10 × $18.50 = $185.00
Total hours = 3 hr setup + (10 × 8/60) = 3 + 1.333 = 4.333 hr
DL = 4.333 × $30 = $130.00
Machine = 4.333 × $60 = $260.00
Overhead = 200% × $130 = $260.00
Total job = $835 → Cost per shaft = $83.50 (vs $39.40 in batch!)
Economic Batch Quantity (EBQ) FORMULA
EBQ = √[ (2 × Annual Demand × Setup Cost) / Holding Cost per unit per year ] Holding cost = Material cost × annual carrying rate (usually ~20%)
// Example from Notes
Demand = 5,000/yr | Setup cost = $42.67 | Holding = $2.77/yr
EBQ = √[(2 × 5000 × 42.67) / 2.77] = √[154,044]
∴ EBQ = 393 units → ~13 batches per year
